# Penalty——双语界面设计

游戏支持英文和简体中文。简体中文为安全默认值；语言选择写入 NVS，退出游戏或
设备重启后恢复。配置缺失、数值无效或存储不可用时回退简体中文，不阻断游戏；
已保存且有效的英文偏好仍会恢复英文。

标题页包含“射门、守门、设置、说明”；设置页包含“难度、音效、语言、返回”。切换
语言后立即刷新当前页面，并在 LVGL／输入路径之外以非阻塞方式排队保存。

两种角色均完成本地化。射门模式统计进球；守门模式统计扑救，并区分接住、扑出、
方向错误、判断正确但未扑到、过早和过晚。守门提示特意控制为适合竖屏底栏的短句，
简单难度或第一球显示教学提示。

英文继续使用现有 Montserrat 字体。中文使用仓库锁定的思源黑体，在 SIL OFL
1.1 许可下生成 14 px 与 20 px 专用子集，只包含游戏实际使用的字形。宿主渲染
必须检查每个本地化字符均有字形，并检查所有可见行均未超过 LVGL 标签宽度。当前
生成子集覆盖两种玩法所需的 191 个本地化字形。

竖屏封面固定展示 `PENALTY` 与“点球决胜”中英双游戏标识，不随界面语言切换。
美术图只保留一个空白开始面板。运行时使用相同字体指标、宽度和纵向位置绘制精简的
`PRESS OK` 或 `按 OK 开始`，切换语言时不会露出旧文字或改变视觉中心，也不在
Flash 中复制整张封面。
