# Penalty 动态文案设计

状态：2026-09-16 已确认并在本地实现；实机可读性待验收。

## 目的

把偏测试信息的 `LINE n-n = GOAL` 数值提示换成简短、轻松的互动文案，同时保留画面中可见的深绿色完美线，不改变射门规则。文案在瞄准和蓄力期间必须保持稳定、适配现有英文字体，并且不能消耗玩法随机数。

## 规则

- EASY 每球显示 `DARK LINE = 90%`。
- NORMAL／HARD 仅第一球显示该教学提示。
- NORMAL／HARD 后续从八句鼓励文案中为每球确定一句，相邻互动球不重复；其第五球固定为 `LAST KICK. NO PRESSURE.`。
- 结果区按普通进球、完美进球、完美扑救、普通扑救、弱射、踢高、超时、绿区进球和绿区扑救分别显示对应轻松解说。
- 瞄准／蓄力之外仍保留最底部的 `HOLD OK: COVER`。游标运行时，文案不移动、不闪烁、不重新随机。

## 实现边界

`main/penalty_copy.c` 是不依赖 LVGL／ESP-IDF 的纯 C 展示规则。它只使用已生成的本球字段和历史射门记录确定文案，不推进或改变玩法随机状态；`penalty_ui.c` 只负责放置选出的字符串。

宿主测试覆盖 EASY／第一球教学边界、选择稳定、相邻不重复、第五球提示、全部结果映射及 28 字符上限。LVGL 测试实际渲染普通互动文案、第五球文案和所有结果，并检查文字宽度及连续 50 次生命周期。
