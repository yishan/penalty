# 点球决胜 v2.0.0 — 联机公开测试版

版本日期：2026-10-06。开源分发入口：[GitHub v2.0.0 Pre-release](https://github.com/yishan/penalty/releases/tag/v2.0.0)。本版为联机公开测试版，不是通过完整耐久验收的稳定版。尚未提交 FoloToy 官方社区，历史社区回执保持不变。

## 本版变化

- 新增附近双设备“点球决胜”：选择“创建联机”或“加入联机”。通过四位大厅码找到对方，核对六位安全码并确认统一难度，再由创建方抛硬币。创建房间不决定先手。
- 两名真人独立选择方向和时机，不显示对手方向提示。双方轮流射门、守门；常规五回合，无法追平时提前结束，平分后成对突然死亡。
- 两端统一显示创建方红衣、加入方蓝衣、门将黑衣。每人各射门一次计为一个回合，单机与联机计数一致。
- 30 秒窗口内恢复连接，不重新抛硬币、不改变已锁定动作、不重复计分。超时无胜负中止；设备重启后不恢复原比赛。
- 加大菜单行距，支持上下循环选择，使用 `>> 选中项 <<` 标记，优化封面文字与红蓝人物比例。保留中英文切换。
- 通过体积优化编译、移除未使用主题、无损字库压缩和裁去透明边缘缩小固件；保持游戏规则与素材可见像素。

## 验证边界

此前双机测试覆盖创建／加入角色互换、结果一致、短时断线恢复与超时无胜负中止。2026-10-06，用户确认第二台精简开发版所请求的菜单、动画和音效检查正常。这些是有范围的观察，不等于本次新版本号普通发布固件已经完成实机验收。

此后已将本次精确普通版 v2.0.0 app 安装到一台设备。写入校验、独立 Flash 校验、分区表未变检查及超过 25 秒启动观察通过，启动版本为 `2.0.0`。这份普通二进制的实体游戏验收仍待完成。完整 M6 矩阵尚未完成：持续比赛、重复恢复／进入退出、全部断线阶段、多大厅、安全／兼容异常、运行资源峰值及仪器级时延／功耗，没有明确实机证据的部分仍为未验证。详见[验证记录](../validation.zh_CN.md)及 [M6 清单](../plans/2026-09-24-ble-duel-v2-design.zh_CN.md)。

## 交付物与安装边界
